# 尺寸刻度类用枚举生成，而非倍数批量生成

本库其余刻度类（间距、字号、字间距）都由倍数批量生成，但宽高刻度 `$size-scale` 是一条手写枚举：小值段密、大值段疏（0~64 逐档，之后跨度递增到 1200）。原因是尺寸与间距的值分布规律不同——间距几乎不超过 200，尺寸常需四位数，若沿用 4/5 倍数密集铺到 1200 会产出上千条规则。枚举让规则数（宽高共约 60 条）与覆盖范围同时可控。

同时刻意**不生成百分比高度类**（无 `.h-[n]p`）：百分比高度仅在父元素有确定高度时生效，否则静默失效，这类"成功率取决于父元素"的工具类违背了"写上就对"的原则。需要满高时用 `.full-size`。百分比宽度无此约束，故 `.w-[n]p` 保留。
